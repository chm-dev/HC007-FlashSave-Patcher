# IPS patches

Generated by `patcher/rom_ips.py` against the original, unpatched ROM.

- `<slug>-hc007.ips` - full patch; includes the 0xFF extension so any IPS tool
  produces the exact output size.
- `<slug>-hc007-min.ips` - minimal patch; apply with
  `--pad-to <size> --pad-byte 0xFF` or let the flasher fill unused banks with
  erased flash.
- `manifest.json` - source/target SHA-1s, patch SHA-1s and file sizes.
- Optional `*-noflash.ips` - debug build that skips journal flash writes.

Verify before publishing:

```powershell
python patcher/rom_ips.py apply ips/<slug>-hc007.ips `
  "path/to/original.gb" rebuilt.gb --expect-sha1 <output-sha1>
```

Keep the original ROM out of version control.  The IPS contains only changed
bytes, new patch code and padding, not the original ROM.
