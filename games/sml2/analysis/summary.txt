Crafted-save proof
------------------
games/sml2/tools/make-save.py creates a valid slot.  Booting it shows Mario and
an occupied A slot on the file-select screen.  See crafted-menu.png.

Patch direction
---------------
- Convert header to MBC5 (0x147 = 0x1B); the game only uses MBC1 mode-0 writes.
- Pad to 1 MiB; log sector 0x80000-0x8FFFF, bank 0x20, CPU 0x6000.
- Save hook: CALL 0x2934 sites -> save_hook.
- Boot restore: hook validator 0x28D9 (preferred) or entry 0x100.
- Journal code: bank 0x1A free run or appended bank; flash stubs in WRAM.
- Open: delete path, bank value at save time, bank restore policy.
